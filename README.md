The full stack project combined different types of frontend development to build a complete and dynamic web application. The Express HTML pages handled the public customer side by serving simple static content and direct interactions through HTML and basic JavaScript. In contrast, the Angular single-page application (SPA) offered more advanced functionality for the administrative side. The SPA allowed smooth data updates without reloading pages and provided reusable components for managing trips efficiently. The backend used a NoSQL MongoDB database because it could easily store flexible, document-based data, making it ideal for handling trip details and user data without requiring strict table structures.

JSON played an important role in connecting the frontend and backend. While JavaScript is a programming language, JSON is a lightweight data format that stores and transfers data between systems. The frontend sent and received data in JSON format through API calls, allowing information to move smoothly between the Angular app and the Express API. During development, some parts of the project were refactored to improve performance, such as cleaning up repeated code and organizing services for trip management. Reusable UI components like forms and cards made it easier to maintain the app and added consistency across different pages.

Testing included verifying API endpoints through tools like Postman to make sure GET and PUT requests worked correctly with the database. Adding authentication created extra steps for testing since the admin side required a valid login token before certain actions could be performed. Understanding endpoints and security helped ensure the application only allowed authorized users to access protected data and that responses were handled safely and accurately.
